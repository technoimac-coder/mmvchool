# หนังสือรับและเกษียนส่งต่อ (e-Office)

เมนูอยู่ในงานอำนวยการ แยกจากงานเอกสารลงนามวิชาการ

1. เจ้าหน้าที่ลงทะเบียนเลขรับ ปีการศึกษา เลขหนังสือ หน่วยงาน เรื่อง เรียน วันที่ จำนวนหน้า หน้าเกษียน ความเร่งด่วน และวันที่ติดตาม
2. เลือกแสดงตรารับหากต้องการ ตรารับจะแสดงบนหน้าแรกของ PDF ฉบับดำเนินการ และอยู่ในไฟล์ที่ดาวน์โหลดจากเครื่องมือลงนาม ต้นฉบับคงเดิม
3. กดเสนอเกษียนและเลือกผู้รับหนึ่งคน ผู้รับได้รับแจ้งเตือนในระบบและ LINE หากเชื่อมบัญชีแล้ว
4. ผู้รับเปิด PDF ใส่ข้อความ วางลายเซ็น และยืนยันบันทึก เมื่อขั้นนี้เสร็จ เจ้าหน้าที่หรือผู้ลงนามคนล่าสุดส่งต่อไปยังผู้บริหาร/หัวหน้างานคนถัดไปได้ ข้อความและลายเซ็นก่อนหน้ายังคงอยู่
5. เมื่อเกษียนเสร็จ กดส่งถึงผู้ปฏิบัติ เลือกได้หลายคนแยกตามกลุ่มสาระ/กลุ่มงาน พร้อมข้อความมอบหมาย ผู้รับแต่ละคนมีงานและการแจ้งเตือนของตนเอง
6. ผู้ปฏิบัติเปิดงานของฉัน กดรับทราบ และรายงานผล เจ้าหน้าที่ผู้ลงทะเบียนได้รับการแจ้งเตือนเมื่อมีรายงานผล
7. เจ้าหน้าที่บันทึกการติดตามและพิมพ์ทะเบียนตามเงื่อนไขที่เลือกได้ จัดเก็บได้เมื่อไม่มีลายเซ็นหรืองานค้าง

ข้อกำหนดรอบนี้: เน้นหนังสือรับเท่านั้น เลขรับกรอกโดยเจ้าหน้าที่และห้ามซ้ำในปีเดียวกัน รองรับไฟล์หลักหนึ่งไฟล์ การเกษียนบนหน้าเอกสารใช้ PDF หนังสือส่ง/คำสั่ง/บันทึกข้อความยังไม่รวมในรอบนี้

- `npm run build` ตรวจ TypeScript และ static export
- `C:/xampp/php/php.exe -l api/eoffice.php` และตรวจเช่นเดียวกันสำหรับ eoffice-actions.php, document_workflows.php
